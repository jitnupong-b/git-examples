# Git Examples - DevOps Course

This repository contains practical Git examples and exercises for learning DevOps fundamentals.

## 📚 Course Structure

### git-i/
Introduction to Git basics:
- Repository initialization
- Basic Git commands (add, commit, status)
- Working with branches
- Understanding the staging area
- Viewing commit history

### git-ii/
Advanced Git concepts:
- Merging and resolving conflicts
- Rebasing
- Remote repositories
- Collaboration workflows
- Git best practices

## 🚀 Getting Started

### Prerequisites
- Git installed on your system ([Download Git](https://git-scm.com/downloads))
- Basic command line knowledge
- A text editor of your choice

### Setup
```bash
# Clone this repository
git clone <repository-url>

# Navigate to the project directory
cd git-examples
```

## 💡 How to Use This Repository

Each folder (`git-i`, `git-ii`) contains:
- Example exercises
- Practice scenarios
- Step-by-step instructions

Work through each module in order to build your Git proficiency progressively.

## 📖 Learning Objectives

By completing these examples, you will:
- ✅ Understand Git fundamentals and version control concepts
- ✅ Master essential Git commands for daily development
- ✅ Learn collaboration workflows using Git
- ✅ Handle merge conflicts confidently
- ✅ Apply Git best practices in real-world scenarios
